## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Check that images and résumé download links work. For a local development server, run `python -m http.server 8000` and open `http://localhost:8000`.

The site is built with **HTML, CSS, and JavaScript**; no framework installation or build step is required.

## Deploy on Vercel

1. Push this repository to GitHub.
2. Visit [vercel.com/new](https://vercel.com/new) and import the GitHub repository.
3. Select **Other** as the framework preset.
4. Set the **Root Directory** to `./` and leave the build command empty.
5. Deploy. Vercel will provide a live URL.

**Future updates:** Commit changes to the production branch (usually `main`). Once GitHub is linked, Vercel automatically redeploys the site.
